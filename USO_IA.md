# Registro de utilização de Inteligência Artificial

Durante o desenvolvimento do Sistema de Locação de Veículos, foi utilizado o ChatGPT (OpenAI) e claude como ferramentas de apoio em algumas etapas do projeto.

## 1. Conexão com o banco de dados

**Atividade:** orientação para configurar a conexão com PostgreSQL utilizando variáveis de ambiente e arquivo `.env`.

**Prompt utilizado:**

"Me ajude a configurar meu projeto Java para utilizar um arquivo .env com os dados de conexão do PostgreSQL, sem deixar a senha exposta no GitHub."

## 2. Operações com o banco de dados

**Atividade:** esclarecimento de dúvidas e auxílio na identificação de erros nas operações de inserção, atualização e remoção de registros.

**Prompt utilizado:**

"Analise os métodos de inserção, atualização e remoção do meu sistema de locação de veículos e me ajude a identificar possíveis erros."

## 3. Organização do GitHub

**Atividade:** orientação sobre organização dos arquivos, criação de commits e publicação do projeto no GitHub.

**Prompt utilizado:**

"Me oriente sobre como organizar os arquivos do projeto no GitHub e separar as alterações em commits de acordo com as atividades realizadas."
